## Key Visual Features

### 1. Gradient Color Scheme
- **Primary**: Blue (#60a5fa) → Purple (#a78bfa) → Pink (#f472b6)
- Used consistently across:
  - Text gradients
  - Border glows
  - Button backgrounds
  - Hover effects

### 2. Glass Effects (Glassmorphism)
- Frosted glass backgrounds
- Backdrop blur (22px)
- Subtle borders with transparency
- Multiple shadow layers for depth

### 3. Glow & Shadow Effects
- Glowing borders on hover
- Animated orbs with blur
- Shadow with color (purple, blue, pink)
- Multiple shadow layers

### 4. Animations
- **Shine Swipe**: Light sweeps across cards
- **Hero Glow**: Pulsing orbs
- **Gradient X**: Animated gradient backgrounds
- **Lattice Pan**: Moving dot grid
- **Orb Drift**: Floating background orbs
- **Page Enter**: Fade in with slide up
- **Hover Effects**: Scale, lift, glow increase

### 5. Typography
- Gradient text on headings
- Animated underlines on section titles
- Font weights for hierarchy
- Letter spacing for impact
